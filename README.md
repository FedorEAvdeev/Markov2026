# Markov2026

Code for STAT 4100 / Markov Processes homework assignments.

## File naming convention

Python files are named using the format

`4100_<homework>_<problem>.py`

For example:

- `4100_2_3.py` = Homework 2, Problem 3
- `4100_2_4.py` = Homework 2, Problem 4

If a problem is split across multiple scripts, an additional number is added:

`4100_<homework>_<problem>_<part>.py`

For example:

- `4100_2_5_1.py` = Homework 2, Problem 5, first script
- `4100_2_5_2.py` = Homework 2, Problem 5, second script

Generated plot images are labeled by homework and problem in the same way.
